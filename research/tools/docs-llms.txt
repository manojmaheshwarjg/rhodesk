 - [Rho API](https://docs.rho.co/api/v1/openapi.md): Programmatic access to Rho's banking, spend, and treasury primitives - accounts, cards, payments, and the transaction ledger. All endpoints take a bearer token in the `Authorization` header. See the [Authentication](/docs/v1/auth) and [Pagination](/docs/v1/pagination) guides to get started. Errors follow [RFC 9457 problem details](https://www.rfc-editor.org/rfc/rfc9457.html); timestamps are ISO 8601 UTC; monetary amounts are integers in the smallest currency unit. v1 is stable and additive-only: changes are backward compatible and breaking changes require a new API version. See the [versioning policy](/docs/v1/versioning).
